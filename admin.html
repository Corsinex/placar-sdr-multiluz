Conexão com o GitHub

Para salvar direto neste site, você precisa de um Personal Access Token do GitHub com permissão de escrita neste repositório. Crie um em github.com/settings/personal-access-tokens/new (tipo Fine-grained, selecione apenas o repositório placar-sdr-multiluz e marque a permissão Contents: Read and write). O token fica salvo apenas neste navegador — não é enviado para lugar nenhum além do GitHub.

Time

Ajuste os agendamentos, troque a foto ou o traço de cada SDR. Depois clique em "Salvar no GitHub" no final da página.

Salvar

Isso vai enviar as fotos novas e atualizar o data.json direto no GitHub. O site publicado atualiza sozinho em cerca de um minuto.
